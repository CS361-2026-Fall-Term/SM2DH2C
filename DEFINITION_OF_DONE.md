# Definition of Done

1. PBI Completion
- Each completed PBI must meet all requirements and the acceptance criteria defined in its GitHub issue description.
- Only when the PBI meets the acceptance criteria and the following points is it considered done.

2. Quality Verification and Code Testing
- The completed code must be tested for its functionality and must be verified that adding this change would not break the existing components.
- Another team member should be able to successfully run the completed code.
- Major bugs that heavily affect the program functionality should be resolved. Minor bugs that do not affect major functionality should still be documented and listed as sub-issues in GitHub for future work.

3. Code Review
- At least one other member of the team must review the code and fix issues when needed.
- Relevant code has been updated to our repository by committing to the corresponding branch.
- Direct commits to the main branch are typically not allowed, and a branch should only be merged through a pull request.
- Update relevant documentation (e.g., README files) for major changes to the system. Examples include introducing new dependencies or changes in program execution instructions.

4. Documentation
- Ensure comments are included in each code component to clearly communicate what the code must execute.
- All commits to GitHub should have clear commit messages.
- For each PBI, link/attach evidence (e.g., screenshots, recordings, test results, etc.) to the corresponding GitHub issue that demonstrates how the completed functionality works.
- The group’s definition of done must be clearly documented on a GitHub README file.

5. Task Completion Updates
- Team members must update their task completion on Microsoft Teams and provide a brief summary of what they have completed. Include relevant links, such as GitHub issues or pull requests.
- Completed work must be recorded or updated on GitHub, including relevant issues, pull requests, and the Project Board/Table. GitHub issues should be updated and closed when all criteria have been met.

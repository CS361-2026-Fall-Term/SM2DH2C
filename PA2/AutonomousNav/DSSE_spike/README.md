# DSSE 

DSSE - Drone swarm search environment uses a probability matrix to created a best guess of where targets are mmost likely to be

### Important notes/findings
Why do the drones not do anything?
- given script has a random policy for drone movements, so we would implement a navigation method/algorithm after location is prioritized for search, which gives us a base to build off of

- needs python 3.10.5 or higher
